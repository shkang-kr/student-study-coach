# 형식 변경 기록

새 성적표에서 중요한 항목이 발견되면 형식 버전과 프로그램 버전을 함께 올리고 여기에 기록해요.

## 형식 v3 (프로그램 v3.0.0, 2026-11-08)

- 학사 일정(schedule)을 추가했어요: 날짜·이름·종류. 학교 이름과 홈페이지 주소는 넣지 않아요
- AI 도구가 만든 결과를 가져오는 약속(kind: reportCard · schedule · examJudgement)을 정했어요
- 비밀번호 암호화 파일(school-coach-encrypted)을 지원해요
- v2 파일은 그대로 불러올 수 있어요(자동 변환)

## 형식 v2 (프로그램 v2.0.0, 2026-11-08)

- 성적표(채점 현황) 샘플 4종을 분석해 형식을 확장했어요
- 시험에 학년·학기·종류를 추가했어요(terms → exams)
- 점수에 실기(performance)와 성적표 총점(reportedTotal)을 추가해 읽기 오류를 검산해요
- 성적표에 인쇄된 합계·평균(reported)을 추가했어요
- 문항별 오답 표기(items): 틀린 문항 번호와 고른 보기, 비운 문항
- 과목에 성적표의 과목 코드(code)를 추가했어요
- 스키마에 없는 항목을 따로 담는 extras를 추가했어요(다음 개정의 근거)
- 이름 변경: scores → results, class.termIds → class.examIds (v1 파일은 자동 변환)

## 형식 v1 (프로그램 v1.0.0, 2026-11-08)

- 최초 형식: 시험·과목·점수(객관식/서술형), 학급 비교, 시험지 분석 예시
