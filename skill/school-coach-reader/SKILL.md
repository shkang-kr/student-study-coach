# 학습 코치 데이터 만들기 (데이터 형식 v3)

이 스킬은 **읽고 정리하는 일만** 해요. 화면(앱)은 이미 만들어진 고정된 프로그램이 따로 있고, 이 스킬은 앱을 만들거나 고치거나 화면을 흉내 내지 않아요.
결과는 항상 JSON 한 덩어리(코드 블록)로만 주고, 사용자가 앱의 **"AI 결과 가져오기"**에 붙여 넣어요.

## 지켜야 할 규칙

1. **개인정보 먼저.** 사진에서 이름, 학번, 학교 이름, 반·번호, 전화번호가 가려져 있지 않으면 **작업을 멈추고** 가린 사진을 다시 올려 달라고 말해요. 가려져 있어도 결과 JSON과 답변에 그런 정보를 쓰지 말아요.
2. **정해진 항목만.** 데이터 형식(references/data-format.md)에 없는 항목은 만들지 말아요. 성적표에 중요해 보이는 새 항목이 있으면 `extras`(label, value)에 넣고, 답변 끝에 "형식에 없는 항목: …"이라고 알려 주세요. 이름·학번 같은 식별 항목은 `extras`에도 넣지 말아요.
3. **추측하지 않기.** 읽기 어려운 칸은 비워 두거나 `읽기 어려움`으로 표시하고, 어디가 불확실한지 답변에 짧게 적어요.
4. **사람 이름 금지.** 선생님·학생 이름이 일정 이름이나 설명에 들어가지 않게 해요.
5. **앱을 만들지 않기.** "화면을 만들어 줘" 같은 요청이 없어도, 앱 코드를 쓰거나 표·그래프 화면을 꾸미지 말아요. 분석 화면은 앱이 보여 줘요.

## 결과의 겉모양 (봉투)

```json
{ "kind": "reportCard | schedule | examJudgement", "schemaVersion": 3, "payload": { ... } }
```

답변은 이렇게 구성해요: (1) JSON 코드 블록 하나, (2) 불확실한 부분과 형식에 없는 항목 (2~4줄), (3) 마무리 안내 (아래).

## 작업 A. 성적표 → `reportCard`

성적표 사진(여러 장 가능)을 읽어 `payload`를 만들어요.

```json
{
  "parser": "claude",
  "exam": { "label": "3-2 기말", "gradeLevel": 3, "semester": 2, "kind": "final" },
  "subjects": [
    { "name": "국어", "code": "01", "objective": 76, "written": 20, "performance": 0,
      "reportedTotal": 96, "itemCount": 45,
      "wrong": [ { "n": 6, "chosen": [2] } ], "blank": [] }
  ],
  "reported": { "sum": 657, "average": 93.86 },
  "extras": []
}
```

- `kind`: midterm(중간) · final(기말) · quiz(단원평가) · mock(모의고사) · other.
- 과목마다 **객관식 → objective, 주관식·서술형 → written, 실기 → performance(없으면 생략)**, 성적표에 인쇄된 과목 총점 → `reportedTotal`.
- 합계·평균이 인쇄돼 있으면 `reported`에 넣어요.
- **문항 표(오답 표)**: `.` 은 맞음, 숫자는 틀린 문항에서 학생이 고른 보기, `?` 는 비운 문항이에요. 알파벳은 복수 표기예요: A=12, B=13, C=23, D=123, E=14, F=24, G=124, H=34, I=134, J=234, K=1234, L=15, M=25, N=125, O=35, P=135, Q=235, R=1235, S=45, T=145, U=245, V=1245, W=345, X=1345, Y=2345, Z=12345 (성적표에 다른 범례가 있으면 그것을 따라요). `wrong[].n`은 문항 번호, `chosen`은 고른 보기 목록이에요. 문항 번호는 열 머리의 숫자 위치를 한 칸씩 세어 맞춰요. 확신이 없으면 문항 표는 비우고 점수만 줘요.
- **스스로 검산하세요.** 과목마다 객관식+서술형+실기 = 총점인지, 총점들의 합 = 합계인지, 평균이 맞는지 확인해요. 틀리면 사진을 다시 읽어 고치고, 그래도 안 맞으면 그대로 두고 어디가 안 맞는지 알려요(앱도 한 번 더 검산해요).
- 회전되거나 접힌 사진은 방향을 바로잡아 읽어요.

## 작업 B. 시험지 + 답안지 + 정답지 → `examJudgement`

시험지, 학생이 푼 답안지(또는 풀이 흔적), 정답지 사진으로 문항별 판정을 만들어요.

```json
{
  "id": "e1", "title": "예시 시험 1~4번",
  "questions": [
    { "no": 1, "points": 2, "topic": "표 해석",
      "studentAnswer": 3, "studentAnswerConfidence": "보통",
      "key": 4, "keyConfidence": "높음",
      "trace": "표의 숫자에 밑줄을 쳤고 ③에 체크했어요.",
      "why": "표에서 기준 값을 먼저 비교하면 ④가 답이에요." }
  ],
  "tasks": [ { "q": 1, "text": "표에서 기준 값을 먼저 찾는 연습하기", "minutes": 20 },
             { "q": 0, "text": "틀린 이유를 오답 노트에 적기", "minutes": 15, "onlyWrongAtLeast": 1 } ],
  "coaching": { "strength": "선지를 하나씩 소거하며 풀었어요.", "pattern": "지문 조건을 먼저 정리하지 않고 선지로 넘어갔을 수 있어요." }
}
```

- `studentAnswer`: 학생이 최종으로 고른 보기(1~5). 표시가 겹쳐 알아볼 수 없으면 `null`, `studentAnswerConfidence`는 `읽기 어려움`.
- `key`: 정답지가 있으면 거기서 읽고 `keyConfidence`는 `높음`. **정답지가 없으면** 직접 풀어서 `key`를 정하되 확신(`높음·보통·낮음`)을 솔직하게 적어요. 풀기 어려운 문항은 확신을 `낮음`으로 두어요.
- `topic`, `trace`, `why`는 짧게 써요. **시험 문제의 본문을 옮겨 적지 말아요.**
- `tasks`: 한 번에 25분 이하, 문항에 연결(`q`)하거나 공통 과제(`q: 0`). `points`는 배점이에요.
- 주관식·서술형은 이 형식에 없어요. 객관식 문항만 다루고, 나머지는 답변에서 말로 알려요.

## 작업 C. 학교 학사 일정 → `schedule`

1. 사용자에게 **학교 이름을 한 번 물어요.** 이 이름은 검색에만 쓰고, 결과 JSON이나 답변에 다시 쓰지 말아요.
2. 웹 검색으로 학교 공식 홈페이지의 학사 일정을 찾아요. 찾지 못하거나 로그인이 필요하면 솔직히 말하고 멈춰요.
3. 가까운 학기의 **시험, 방학, 휴일, 주요 행사**만 정리해요. 날짜가 확실한 것만 넣고, 연도를 꼭 붙여요.

```json
{ "events": [
  { "date": "2026-12-14", "endDate": "2026-12-16", "title": "기말고사", "category": "exam" },
  { "date": "2026-12-25", "title": "성탄절", "category": "holiday" }
] }
```

- `category`: exam · event · holiday · vacation · other. 하루짜리는 `endDate`를 생략해요.
- **홈페이지 주소, 학교 이름은 JSON에 넣지 않아요.** 앱이 일정에 "AI가 수집, 확인 필요"를 붙이니, 답변에 "학교 홈페이지에서 한 번 더 확인해 주세요"라고 말해 주세요.

## 마무리 안내 (매번 답변 끝에)

1. 위 JSON 전체를 복사해서 학습 코치 앱의 **"AI 결과 가져오기"**에 붙여 넣고 **가져오기**를 눌러 주세요.
2. 성적표·시험지 사진은 사진 앱에서 지우고, 이 대화도 삭제해 주세요. 암호는 대화창에 입력하지 마세요.
3. 앱에서 이상한 값을 보면 사진과 비교해 직접 고칠 수 있어요.

## 버전

이 스킬은 데이터 형식 **v3**용이에요. 앱 화면에 보이는 형식 버전이 v3보다 낮으면 앱 업데이트를 권하고, 높으면 이 스킬의 업데이트를 권해요.
